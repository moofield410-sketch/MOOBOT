# Moofield X posters (meadow theme)

Two images for X, drawn in the same style as the website: sky-to-hay sky, a thin gold sun ring,
pale hills, the Pollen Path flowers and the Bloom Pop seeds.

| File | Use |
| --- | --- |
| `moofield-article-cover.png` (3000 x 1200, 5:2) | Cover image for an X Article. "Welcome to Moofield", with MooBot, Bumble and Crowley named |
| `moofield-token-live.png` (3200 x 1800, 16:9) | Image for the "$MOOBOT is live" post. Happy MooBot, Bumble bringing a coin, Crowley in a party hat |

`article-cover.html` and `token-live.html` are the sources; `kit.js` holds the shared drawings
(MooBot, Bumble, Crowley, seeds, flowers, hills). The PNGs are 2x screenshots of the HTML pages.

The live poster tells people to copy the contract only from the website or the pinned post.
To print the real address on it instead, open `token-live.html?ca=0x...` (a full 42-character address)
and take the screenshot again.

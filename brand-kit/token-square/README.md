# $MOOBOT token image (square)

MooBot's face as big as it fits, on the meadow from the website, filling the whole square.
No ring or badge, so it looks right on launch sites that show the full square image,
and still works on sites that crop it to a circle.

| File | Use |
| --- | --- |
| `moobot-token-1000.png` (1000 x 1000) | Upload this one as the token image |
| `moobot-token-512.png` (512 x 512) | Smaller copy, if a site asks for 512 x 512 or a smaller file |

`token.html` is the source (it uses the drawings in `../x-posters/kit.js`); the PNGs are screenshots of it.
